# 📚 Agentic-RAG-English-Tutor: Local RAG System for English Learning

A privacy-focused, local Retrieval-Augmented Generation (RAG) system built with LangChain, ChromaDB, and Ollama (Llama 3.2) to analyze and interact with English learning materials offline.

## 🚀 Features
- 🔒 100% Local Processing: No API keys or external server calls required.
- ⚡️ Fast Vector Retrieval: Powered by ChromaDB & HuggingFace Embeddings.
- 💬 Smart Conversational AI: Powered by Ollama (llama3.2).
- 📄 PDF Processing: Automated ingestion and text splitting using LangChain.
